# Чистка логов — дизайн

Дата: 2026-08-20
Платформа: macOS (Apple Silicon, macOS 15+)
Язык/фреймворк: Swift 6 + SwiftUI
Сборка: без Xcode — только Command Line Tools (swiftc/swift + codesign), сборка `.app` вручную скриптом.

## Цель

Нативное приложение для macOS, которое даёт **хозяину компьютера** просмотреть логи
приложений, которыми он пользовался, и **безвозвратно удалить** выбранные — целиком
или за выбранный период. Смысл проверки владельца — подтвердить, что за компьютером
его настоящий хозяин, и это не способ добраться до чужих данных.

## Поток экранов

### Экран 1 — Согласие + вход
- Заголовок «Это ваш компьютер?», крупная кнопка **Да**.
- По нажатию — системная проверка macOS через `LocalAuthentication` (Touch ID, при
  недоступности — системный пароль).
- Успех → Экран 2. Отмена/ошибка → остаёмся на Экране 1 с пояснением.

### Экран 2 — Таблица приложений
- Белый фон, чёрный текст.
- Одна строка на приложение, у которого нашлись логи:
  `Название | N файлов, размер | [Да] [Нет]`.
- **Да** — зелёная, ведёт на Экран 3. **Нет** — красная, ничего не удаляет.
- После возврата с Экрана 3 цифры строки пересчитываются; если логов не осталось —
  строка исчезает.

### Экран 3 — Детали приложения + период
- Показывает логи выбранного приложения (список файлов: имя, размер, дата).
- Кнопки:
  - Удалить всё
  - Удалить за последний день
  - Удалить за последнюю неделю
  - Удалить за последний месяц
- Перед удалением — окно подтверждения «Точно стереть насовсем? Да / Нет».
- Удаление **безвозвратное** (`FileManager.removeItem`, не Корзина).
- Показываем итог: сколько файлов и сколько места удалено.

## Где ищем логи

- `~/Library/Logs/` — логи приложений пользователя (папка = приложение → группировка).
- `~/Library/Logs/DiagnosticReports/` — отчёты о сбоях.
- `/Library/Logs/` — общие логи.

Группировка: имя подпапки/приложения = строка таблицы. Для каждой строки считаем
число файлов, суммарный размер, дату последнего изменения.

## Удаление по периоду

- Фильтр по дате изменения файла (`contentModificationDate`).
  - день = за последние 24 ч, неделя = 7 дней, месяц = 30 дней.
- «Удалить всё» — все файлы приложения без фильтра по дате.
- Стираем только реальные файлы логов; папки приложения не трогаем, если в них
  остались файлы вне выбранного периода.

## Доступ (Full Disk Access)

Чтобы читать/удалять логи чужих приложений, macOS один раз попросит выдать
приложению **«Полный доступ к диску»** (Системные настройки → Конфиденциальность и
безопасность → Полный доступ к диску). Без него будет виден лишь ограниченный набор.
Приложение при старте проверяет доступ и, если его нет, показывает понятную подсказку
с кнопкой открытия нужного раздела настроек.

## Риск: Touch ID без Xcode

`LocalAuthentication` требует, чтобы бинарник был подписан. Планируем ad-hoc подпись
через `codesign` (входит в Command Line Tools). Это первый пункт для проверки: если
Touch ID на ad-hoc-подписи не заведётся, откат — использовать системный пароль
(`LAPolicy.deviceOwnerAuthentication` уже включает пароль как запасной путь), и лишь в
крайнем случае — установка Xcode.

## Архитектура кода (модули)

- `AuthService` — обёртка над `LocalAuthentication`. Вход: запрос проверки. Выход:
  успех/ошибка. Не знает про UI.
- `LogScanner` — сканирует известные каталоги, возвращает модель:
  `[AppLogs]` где `AppLogs { name, files: [LogFile] }`,
  `LogFile { url, size, modified }`. Не удаляет ничего.
- `LogDeleter` — принимает список файлов (или приложение + период), удаляет
  безвозвратно, возвращает отчёт `{ deletedCount, freedBytes, errors }`.
- `PermissionChecker` — проверяет наличие Full Disk Access, открывает настройки.
- SwiftUI-слой: `ConsentView`, `AppListView`, `AppDetailView`, `ConfirmDialog` —
  только отображение, вся логика в сервисах выше.

Каждый сервис тестируется отдельно; UI обращается к ним через простые интерфейсы.

## Сборка (без Xcode)

- Swift Package (executable target) c зависимостью на SwiftUI/AppKit.
- Скрипт `build.sh`: `swift build -c release`, затем сборка бандла
  `Чистка логов.app` (папки `Contents/MacOS`, `Contents/Resources`, `Info.plist` с
  `NSFaceIDUsageDescription`/`NSPrincipalClass`), ad-hoc подпись `codesign -s -`.
- Результат — двойным кликом открываемое приложение.

## Тестирование

1. **Песочница:** тесты `LogScanner`/`LogDeleter` на временной папке с фейковыми
   логами разных дат — проверяем, что удаляются ИМЕННО нужные файлы и ИМЕННО за
   выбранный период, размеры считаются верно.
2. **Touch ID:** ранняя проверка на ad-hoc-подписи (риск выше).
3. **Реальные логи:** только после успешной песочницы; сначала на одном приложении.

## Явно вне рамок (YAGNI)

- Не чистим кэш/историю браузера/куки — только логи.
- Нет расписаний/автоочистки, нет облака, нет настроек — одна прямая задача.
- Не трогаем системные логи, требующие root (unified logging БД) — только файлы логов,
  доступные пользователю.
