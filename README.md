# Чистка логов

Нативное приложение для macOS: посмотреть логи приложений, которыми ты пользовался,
и **безвозвратно удалить** выбранные — целиком или за период (день / неделя / месяц).

Смысл входа через Touch ID / пароль — подтвердить, что за компьютером его хозяин.
Приложение работает только с логами, к которым у тебя и так есть доступ на твоём Mac.

## Возможности

- Экран «Это ваш компьютер?» → подтверждение через **Touch ID или системный пароль**.
- Список приложений с логами: сколько файлов и сколько места.
- Переключатель **«Показывать все приложения»** — видно и те, у кого логов нет.
- Удаление логов приложения: **всё / за последний день / неделю / месяц**,
  с подтверждением «точно стереть насовсем?».
- Подсказка про **Полный доступ к диску**, если система не пускает к части логов.

## Сборка (без Xcode)

Нужны только Command Line Tools (`swiftc`). Xcode не требуется.

```bash
./build.sh
open "build/Чистка логов.app"
```

## Тесты

Проверяют сканер и удаление по периодам на временной «песочнице» — реальные логи
не трогаются.

```bash
./run_tests.sh
```

## Как это работает

- `LogScanner` — ищет логи в `~/Library/Logs`, `/Library/Logs` и группирует по приложениям.
- `LogDeleter` — удаляет файлы безвозвратно (`FileManager.removeItem`, не Корзина).
- `AppLister` — список установленных приложений (для режима «показать все»).
- `AuthService` — Touch ID / пароль через `LocalAuthentication`.
- SwiftUI — три экрана в `App.swift`.
